Atualização para Python 3.14

Guardião 2 · dependências, instaladores e validação · 10/11/2026

Resumo. O projeto foi escrito para o Python 3.12 e não instalava no 3.14, porque o NumPy 2.2.6 e o Pillow 11.3 não têm pacote pronto (wheel) para essa versão. Atualizei as versões, ajustei os instaladores e a verificação de versão, e conferi tudo com os testes do projeto. Nenhuma linha da aplicação em biometria/ foi alterada. Nenhuma regra de acesso, de autenticação ou do reconhecimento facial mudou.

Por que não usei a versão mais nova de tudo

Existe o OpenCV 5.0, mas ele troca o motor das redes neurais (DNN) e emite avisos na inicialização. Fiquei na série 4.x, que é a mesma geração usada e validada no projeto. Com o 4.13 o aviso não aparece.

3. O que cada mudança faz

  • Versões do requirements.txt: é a lista que o instalar.bat manda o pip instalar no venv. Com as versões antigas, o pip tentava compilar o NumPy no 3.14 e falhava. Com as novas, ele baixa pacotes prontos.
  • instalar.bat: cria o ambiente isolado .venv chamando o Python pelo Launcher (py). Agora pede a versão 3.14. Quem tiver só o 3.12 precisa ajustar de volta, ou instalar o 3.14.
  • verificar.py: é o diagnóstico que o instalador roda no final. Ele checa a versão do Python, carrega os dois modelos ONNX e testa uma imagem sem rosto. O limite de versão superior era 3.13, por isso falharia no 3.14 mesmo com tudo instalado.
  • pytest 9.2.0: com o pytest 8.4.2 no Windows, dois testes de "imagem inválida" falhavam. Um dos parâmetros do teste é uma sequência de 5 MB de "x", e o pytest copia o nome do teste para uma variável de ambiente. O Windows limita esse valor a 32.767 caracteres. A falha acontece no teste, não na aplicação, e não aparecia na validação original porque ela foi rodada em Linux. O pytest 9.2.0 não tem o problema.

5. Limites desta validação

  • As imagens usadas nos 2 testes de inferência real foram as duas amostras públicas citadas no VALIDACAO.md (Lena, do OpenCV, e astronaut, do scikit-image). Elas confirmam que o motor roda e distingue duas pessoas, mas não medem precisão em pessoas reais.
  • Não foram testados: webcam, a interface no navegador (layout e JavaScript) e a execução real dos arquivos .bat. Só o texto dos .bat foi alterado.
  • Os bancos instance/ existentes não são afetados. As versões novas leem o mesmo SQLite e os mesmos vetores faciais.
  • Quem quiser continuar no Python 3.12 pode, mas precisa usar as versões antigas do requirements.txt e reverter o instalar.bat.
